# 쇼핑몰 연동 리뷰

## 고객사 요구사항

### 1. 고객사 핵심 요구사항 이행 결과

#### **페이지 간의 자연스러운 연결 및 이동**
* **끊김 없는 화면 전환:** 메인 화면에서 상품을 클릭해 상세 페이지로 들어가거나, 장바구니에서 결제 화면으로 이동하는 모든 과정이 매끄럽게 연결되도록 구현되었습니다.
* **직관적인 뒤로가기:** 상세 페이지나 결제 페이지 어디서든 이전 단계로 쉽게 돌아갈 수 있는 버튼을 배치하여 사용자가 길을 잃지 않게 설계했습니다.

#### **데이터 일관성 유지 (어디서든 동일한 정보 노출)**
* **실시간 장바구니 업데이트:** 메인 화면이나 상세 페이지에서 상품을 담으면, 상단 바에 있는 숫자 배지가 즉시 업데이트되어 사용자가 담은 상품 개수를 바로 확인할 수 있습니다.
* **새로고침 시 데이터 보존:** 페이지를 새로고침하거나 브라우저를 껐다 켜더라도, 이전에 담아둔 장바구니 목록과 등록한 카드 정보가 사라지지 않고 그대로 유지됩니다.

---

### 2. 추가 요구사항 (피그마 시안) 반영 내역

#### **상품 상세 페이지 구현**
* **상세 정보 확인:** 선택한 상품의 큰 이미지와 설명, 가격을 한눈에 볼 수 있는 전용 페이지를 추가했습니다.
* **수량 조절 기능:** 상세 페이지 내에서 구매하려는 수량을 자유롭게 조절할 수 있으며, 이에 맞춰 가격이 실시간으로 계산됩니다.
* **추천 상품 노출:** 현재 보고 있는 상품과 같은 브랜드의 다른 신발들을 하단에 추천해 주어 추가 쇼핑을 유도합니다.

#### **결제 완료 페이지 구현**
* **최종 구매 확인:** 결제가 성공적으로 끝나면 '결제 완료!' 메시지와 함께 총 몇 개의 상품을 얼마에 구매했는지 명확하게 안내하는 화면을 구현했습니다.
* **메인으로 돌아가기:** 결제 후 다시 쇼핑을 시작할 수 있도록 상품 목록으로 바로 이동하는 버튼을 포함했습니다.
