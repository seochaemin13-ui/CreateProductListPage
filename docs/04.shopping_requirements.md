# 쇼핑몰 연동 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
패션 쇼핑몰 연동 및 상세 페이지 제작

### 사용하게 될 기술: 
- React
- `react-router-dom` (페이지 간 이동 처리: 상품목록 ↔ 카드목록 ↔ 카드추가)
- `React Context API` (카드 목록 전역 관리) 또는 `useState`, `useEffect` (전역 상태 및 localStorage 동기화)
- css

### 문서 작성자: 
서채민

## 📝 고객 요구사항 정리
- 상세 페이지
- 페이지 연동

## 📋 기능 목록
- 상세 페이지
  - 카드를 누르면 이동
  - 가격, 수량, 장바구니 담기 버튼, 관련 상품, 설명 존재
  - 관련 상품은 자동으로 스크롤 돼서 보여짐. 사용자가 스크롤 해도 가능.
  - 수량 변경 여기서도 가능
- 페이지 연동
  - 어디서 뭘 누르든 일관된 상태 유지
- 결제 완료 창
  - 결제하기 눌렀을때 가격과 함께 결제 되었다는 창이 뜸.
  - 상품 목록으로 돌아가기 버튼으로 돌아갈수 있음.
