# 쇼핑몰 연동

## 프로젝트 개요

- 사용자가 상품을 탐색하고 장바구니에 담는 기본적인 쇼핑몰 기능부터, **보안이 강화된 카드 등록 및 결제 프로세스**를 경험할 수 있는 React 기반의 프론트엔드 웹 애플리케이션입니다.

* **주요 기능**
    * **상품 상세 및 관련 상품 추천:** 상품의 상세 정보를 확인하고, 동일 브랜드의 다른 상품을 추천받는 기능을 제공합니다.
    * **고도화된 카드 등록 폼:** 카드 번호 분할 입력, 자동 포커스 이동, 마스킹 처리, CVC 툴팁 등 실제 금융 앱 수준의 사용자 경험을 제공합니다.
    * **보안 데이터 관리:** `CryptoJS`를 사용하여 사용자의 민감한 카드 정보를 암호화하여 저장하고 필요 시에만 복호화하여 사용합니다.
    * **유연한 결제 로직:** 장바구니 전체 결제와 상품 상세 페이지에서의 즉시 결제(단일 상품)를 모두 지원합니다.

- 참여한 팀원: [![GitHub Badge](https://img.shields.io/badge/GitHub-seochaemin13--ui-181717?style=flat-square&logo=GitHub&logoColor=white)](https://github.com/seochaemin13-ui)

## 개발 환경

* **Framework:** `React 18.3.1` (Vite 빌드 도구 활용)
* **State Management:** `Recoil` (전역 상태 및 파생 상태 관리)
* **Routing:** `React Router Dom`
* **Security:** `CryptoJS` (AES 알고리즘 기반 데이터 암호화)
* **Styling:** CSS3 (반응형 설계를 위한 `clamp()` 및 `Container Queries` 활용)

## 설치 및 실행 방법

프로젝트를 로컬 환경에서 실행하려면 아래 명령어를 입력하세요.

```
# 의존성 패키지 설치
npm install

# 로컬 개발 서버 실행 (Vite)
npm run dev # 또는 설정에 따라 npm start
```

## 주요 함수와 기능

* **암호화 로직 (`encryptData`, `decryptData`):** `SECRET_KEY`를 기반으로 사용자의 카드 번호, CVC, 비밀번호를 AES 알고리즘으로 암호화하여 `localStorage`에 안전하게 보관합니다.
* **가격 합산 및 배송비 정책 (`cartPriceSummaryState`):** Recoil Selector를 활용하여 상품 총액이 100,000원 이상일 경우 배송비 3,000원을 자동으로 0원으로 변경하는 비즈니스 로직을 처리합니다.
* **카드 유효성 검사:** 만료일이 현재 날짜보다 이전인지 확인하는 `isValidExpiryDate` 함수를 통해 잘못된 카드 등록을 방지합니다.
* **동적 UI 인터랙션:** 카드 번호 4자리를 모두 입력하면 자동으로 다음 입력 칸으로 포커스가 이동하는 `handleCardNumberChange` 기능을 구현했습니다.


## 테스트 방법

```
npm test
```
* **주요 테스트 케이스**
    * **결제 금액 검증:** 상품 상세에서 수량을 조절했을 때 총 결제 금액이 정확히 계산되는지 확인합니다.
    * **카드 마스킹 테스트:** 카드 목록 페이지에서 카드 번호의 앞 8자리만 노출되고 뒷부분은 마스킹(`•`) 처리되는지 확인합니다.
    * **결제 후 상태 변화:** 결제 완료 시 장바구니가 비워지고 결제 성공 페이지로 데이터가 정상 전달되는지 확인합니다.


## 유의사항 및 알려진 이슈

* **암호화 키 관리:** 현재 `SECRET_KEY`가 클라이언트 소스 코드에 노출되어 있으므로, 실제 서비스 시에는 환경 변수(`.env`)로 관리하거나 백엔드에서 처리해야 합니다.
* **이미지 경로:** `BASE_URL` 설정에 따라 이미지 파일(`img/*.jpg`)이 정상적으로 로드되지 않을 수 있으므로 환경 설정 확인이 필요합니다.
* **Luhn 알고리즘:** 카드 번호 유효성 검사 로직인 `isValidLuhn`은 현재 코드상에 구현되어 있으나 사용자 편의를 위해 주석 처리되어 있습니다.
