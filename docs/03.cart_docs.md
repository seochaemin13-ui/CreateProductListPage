# 장바구니 프로젝트

## 프로젝트 개요
사용자가 상품을 탐색하고, 장바구니에 담아 수량을 조절하며, 안전하게 결제 수단(카드)을 등록할 수 있는 반응형 웹 쇼핑몰 프론트엔드 프로젝트.

- 주요 기능
  - **상품 목록 조회 및 필터링:** Mock API를 통해 실시간으로 상품 데이터를 불러와 전시합니다.
  - **동적 장바구니 시스템:** 상품 담기/해제, 수량 증감에 따른 실시간 금액 계산 및 배송비 정책(10만 원 이상 무료)을 적용합니다.
  - **데이터 지속성:** `localStorage`를 활용하여 새로고침 후에도 장바구니 아이템과 수량이 유지됩니다.
  - **보안 카드 등록:** `CryptoJS`를 이용해 카드 번호, CVC 등 민감 정보를 암호화하여 저장하며, 유효기간 및 카드 번호 유효성 검증을 수행합니다.
  - **반응형 UI:** CSS `clamp()` 함수를 활용하여 모바일부커 데스크탑까지 유연하게 대응하는 디자인을 구현했습니다.

- 참여한 팀원: 서채민

## 개발 환경

* **React**: `^18.3.1`
* **상태 관리**: `Recoil`
* **API 모킹**: `MSW (Mock Service Worker)`
* **Security**: `CryptoJS (AES-256 Encryption)`
* **빌드 도구**: `Vite`

## 설치 및 실행 방법

프로젝트를 로컬 환경에서 실행하려면 아래 명령어를 입력하세요.

```
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm start
```

## 컴포넌트 구조

| 컴포넌트명 | 역할 설명 |
| --- | --- |
| **`App.jsx`** | 페이지 라우팅 제어 및 전역 상태(`localStorage`) 동기화 |
| **`Cart.jsx`** | 장바구니 로직(수량 조절, 합계 계산, 배송비 산출) 담당 |

## 테스트 방법

```
npm test
```

- **주요 검증 항목**
  - **상품 금액 표시**: 장바구니에 담긴 상품(신발A)의 가격인 30,000원이 요약 영역에 정상적으로 나타나는지 확인합니다.
  - *배송비 부과**: 상품이 존재할 때 기본 배송비인 3,000원이 자동으로 합산되는지 확인합니다.
  - **Recoil 상태 주입**: RecoilRoot의 initializeState를 통해 초기 Mock 데이터(상품 목록, 장바구니 아이템, 수량)가 컴포넌트에 올바르게 전달되는지 테스트합니다.

## 유의사항 및 알려진 이슈

* **MSW 활성화**: 개발 환경에서 API 모킹을 위해 서비스 워커가 정상적으로 등록되어야 상품 목록이 표시됩니다.
* **최소 수량**: 장바구니 내 상품은 최소 1개 이상을 유지해야 하며, 삭제를 원할 경우 수량을 조절하는 로직이 적용되어 있습니다.
