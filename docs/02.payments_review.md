# 결제 모듈 리뷰

## 고객사 요구사항

- 상품 목록 페이지의 구매 버튼
- 카드 관리 및 등록
  - 보유 카드 상태별 대응
  - 실시간 카드 정보 미러링
  - 입력 폼
## 요구사항에 따른 기능 동작 확인

| 구분 | 기능 동작 확인 항목 | 기대 결과 |
| --- | --- | --- |
| **구매 버튼** | 구매 버튼 선택시 보유 카드 목록창으로 이동 | 보유 카드 헤더와 창을 나갈수 있는 (X) 버튼이 위에 정상 노출 |
| **카드 목록** | 등록된 카드가 없는 초기 상태 확인 | 안내 문구와 중앙 추가(+) 버튼이 정상 노출됨 |
| **카드 등록** | 카드번호 입력 시 플레이트 반영 | 입력한 번호가 상단 카드 이미지의 번호 영역에 실시간으로 나타남 |
| **카드 등록** | 소유자명 및 만료일 입력 반영 | 사용자가 입력한 영문 이름과 날짜가 카드 플레이트 위치에 정확히 배치됨 |
| **카드 등록** | 입력 필드 유효성 검사 | 필수 항목(번호, 날짜, CVC 등) 미입력 시 '작성 완료' 버튼이 활성화되지 않음 |
| **카드 등록** | 카드 등록 완료 프로세스 | 모든 정보 입력 후 '작성 완료' 클릭 시 보유 카드 목록으로 이동하며 신규 카드가 추가됨 |
| **카드 목록** | 카드 표시 확인 | 등록 완료된 카드에 작성한 정보들이 표시됨 |
