## 📝 고객 요구사항 정리

1. **정확한 금액 산출:** 장바구니에 담긴 상품의 개별 금액 합계가 '상품 금액'에 정확히 반영되어야 함.
2. **동적 금액 계산:** 장바구니 내 상품들의 수량을 변경할 때마다 상단 총 금액이 정확히 계산되어야 함.
3. **배송비 정책 적용:** 합계 금액이 **100,000원 미만**일 경우 배송비 **3,000원** 부과, **100,000원 이상**일 경우 **무료(0원)** 처리.
4. **내비게이션 기능:** 상단 '뒤로가기(←)' 버튼을 클릭하면 메인 상품 목록 페이지로 이동해야 함.
5. **결제 페이지 진입:** 하단 '결제하기' 버튼 클릭 시,  이미 제작된 **결제 모듈 페이지**로 이동함.


## 📋 기능 목록

| 구분 | 기능 명칭 | 상세 내용 |
| --- | --- | --- |
| **연산** | **상품 총 금액 계산** | - 각 상품의 (단가 $\times$ 수량)을 전역 또는 로컬 상태로 합산 |
| **연산** | **배송비 조건부 렌더링** | - 합계 금액에 따른 배송비 산출 ($<10$만: 3,000 / $\ge10$만: 0) |
| **연산** | **최종 결제 금액 업데이트** | - (상품 총액 + 배송비)를 '총 금액' 영역에 최종 표시 |
| **상태** | **수량 증감 컨트롤** | - `+`, `-` 버튼으로 수량 변경. (최소 수량 1개 유지 로직 포함) |
| **이동** | **상품 목록(메인) 복귀** | - 상단 뒤로가기 버튼 클릭 시 메인 페이지로 경로 이동 |
| **이동** | **결제 UI 페이지 이동** | - '결제하기' 버튼 클릭 시 **기존 제작한 카드 관리 페이지**로 이동 |


### 🛠️ 구현을 위한 로직 가이드

**1. 배송비 및 총액 계산 (React 로직 예시)**

```javascript
const itemTotal = cartItems.reduce((sum, item) => sum + item.price * item.quantity, 0);
const shippingFee = itemTotal >= 100000 ? 0 : 3000;
const finalTotal = itemTotal + shippingFee;
```

**2. 페이지 이동 (useNavigate 활용)**

```javascript
import { useNavigate } from 'react-router-dom';

const CartPage = () => {
  const navigate = useNavigate();

  return (
    <>
      {/* 뒤로가기 버튼 */}
      <button onClick={() => navigate(-1)}>←</button> 

      {/* 결제하기 버튼: 기존에 만드신 카드 등록 페이지 경로로 이동 */}
      <button onClick={() => navigate('/payment')}>결제하기</button>
    </>
  );
};
```
