# 장바구니 페이지 리뷰

## 고객사 요구사항
* **실시간 수량 조절**: 장바구니 안에서 상품 개수를 즉시 변경하고, 그에 따라 금액이 바로 계산됨.
* **배송비 자동 계산**: 총 구매 금액에 따라 배송비가 0원 혹은 3,000원으로 자동 전환됨 (10만 원 이상 무료 배송).
* **뒤로가기 버튼**: 장바구니에서 뒤로가기 버튼 클릭 시 메인 화면(상품 목록 페이지)로 이동됨.
* **결제 단계 진입**: 장바구니에서 '결제하기' 버튼 클릭 시 미리 등록된 카드 목록이나 결제 페이지로 자연스럽게 연결됨.

## 요구사항에 따른 기능 동작 확인

### 1. 실시간 수량 조절 및 금액 계산

* **동작 상태**: **정상 작동**
* **상세 설명**:
* 상품 우측의 `+` 또는 `-` 버튼을 누르면 상품의 개수가 즉시 변경됩니다.
* 개수가 변할 때마다 하단의 '상품 금액'과 '총 금액'이 별도의 새로고침 없이 실시간으로 합산되어 표시됩니다.
* 최소 수량은 1개로 설정되어 있어, 실수로 상품이 화면에서 사라지는 것을 방지했습니다.

### 2. 배송비 자동 계산 (10만 원 기준)

* **동작 상태**: **정상 작동**
* **상세 설명**:
* 담은 상품들의 총 금액이 **100,000원 미만**일 때는 배송비 **3,000원**이 자동으로 부과됩니다.
* 수량을 늘려 총 금액이 **100,000원 이상**이 되는 순간, 배송비 항목이 **0원**으로 즉시 변경되어 무료 배송 혜택이 적용됩니다.
* 장바구니가 비어있을 때는 배송비가 중복 계산되지 않도록 0원으로 처리됩니다.

### 3. 뒤로가기 버튼

* **동작 상태**: **정상 작동**
* **상세 설명**:
* 장바구니 페이지 왼쪽 상단의 화살표(`←`) 버튼을 클릭하면 구매하던 상품 목록 페이지로 즉시 이동합니다.
* 페이지 이동 시 기존에 담아두었던 상품 리스트와 수량 정보는 초기화되지 않고 안전하게 유지됩니다.

### 4. 결제 단계 진입

* **동작 상태**: **정상 작동**
* **상세 설명**:
* 장바구니 하단의 **'결제하기'** 버튼을 클릭하면 등록된 카드 정보를 확인할 수 있는 '나의 카드 목록' 페이지로 연결됩니다.
* 상품이 하나도 담겨있지 않을 때는 결제 버튼이 화면에 나타나지 않도록 처리하여 잘못된 주문을 사전에 차단했습니다.
